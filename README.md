# 量化投资实战：基于双均线策略的沪深300ETF回测分析

 📌 项目背景
本项目旨在利用Python，结合经济统计学原理，对A股宽基指数（沪深300ETF）进行量化回测。验证趋势跟踪策略（动量效应）在震荡及熊市环境下的风险控制能力。

 🛠️ 技术与工具
   数据获取：AkShare (免费开源金融数据接口)
   数据处理：Pandas, Numpy
   可视化：Matplotlib
   核心逻辑：基于10日/60日均线（金叉买入，死叉卖出）的动量策略

 📊 回测设置
   测试标的：沪深300ETF (510300)
   回测区间：2020年1月 - 2024年12月
   交易成本：双边 0.15%（计入真实摩擦成本）

 🏆 核心回测结果 (2020-2024)
对比“买入并持有”基准，策略表现如下：

| 核心指标 | 买入并持有 (基准) | 10/60日均线策略 | 策略优势 |
| :--- | :--- | :--- | :--- |
| 累计收益率 | -3.06% | +3.48% | 逆势实现正收益 |
| 最大回撤 | -45.10% | -32.21% | 显著降低尾部风险，提升持仓体验 |
| 夏普比率 | 0.07 | 0.12 | 风险调整后收益性价比近翻倍 |

 💡 统计分析与结论
 
1. 过滤噪音：将均线窗口从短周期（5/20）拉长至中长周期（10/60），有效过滤了震荡市中的假信号，减少了交易磨损。
2. 风控价值：在2022-2024年的单边下跌行情中，策略通过死叉信号及时空仓，成功避开主跌浪，将最大回撤从45%压制在32%左右。
3. 动量效应：证明了A股市场存在一定的趋势惯性，严格执行交易纪律能有效克服人性弱点。
